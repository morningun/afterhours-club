# AFTERHOURS — 3D Club

Three.js 기반 단일 HTML 3D 클럽 씬. 브라우저에서 바로 걸어다닐 수 있습니다.

## 조작
- 드래그: 시점 회전
- `WASD` / 방향키: 이동
- `SHIFT`: 달리기
- `F` 또는 `DANCE` 버튼: 춤추기 (이동하면 해제)
- 모바일: 좌측 하단 가상 조이스틱, 우측 하단 `DANCE`

## 특징
- three.js r160 + 후처리(블룸)를 파일 안에 인라인으로 포함 — CDN/인터넷 불필요
- 절차적 걷기 애니메이션과 비트 동기화된 3단 춤 루틴
- 3인칭 추적 카메라, 포인터 캡처 기반 드래그 회전
- Web Audio로 실시간 생성하는 하우스 비트 (`SOUND OFF` 버튼)
